# ArenaNecromante--GodotGame

Meu primeio jogo, um projeto simples feito em 12 dias na Godot 4

O projeto foi desenvolvido como um exercício de programação e desenvolvimento de jogos, por isso a estrutura e organização dos nodes e do código são notoriamente amadores e sem muito polimento.
A proposta era trabalhar com um MVP pequeno e um prazo definido, evitando expandir o projeto indefinidamente.


## Sobre o Jogo

Objetivo: Sobreviver 180 segundos (3 minutos) enquanto enfrenta os inimigos, ganha xp e aprimora o personagem, enfrentando ondas de inimigos cada vez mais fortes

Ao final desses 180 segundos o boss final aparece, derrote-o para concluir o jogo


## Arte

Todos os sprites utilizados no projeto foram produzidos durante o desenvolvimento, contudo para essa versão todos os sprites são placeholderes.

Como o objetivo era ter algo funcional e dentro do prazo, a arte visual não foi priorizada


## Efeitos sonoros

É notável que não há nenhum no projeto inteiro, isso ocorre pelo mesmo motivo da parte visual, não foi priorizado e por conta disso ainda não foi adicionado


## Motivação

Este projeto faz parte de uma série de pequenos experimentos destinados a praticar desenvolvimento de jogos através de projetos com escopo reduzido, prazo definido e uma linha de chegada clara.
